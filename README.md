# Saigonesee Catering

Catering menu for Saigonesee (39 Trotter Rd, South Weymouth, MA): Banh Mi Platter + Drinks priced per guest by group size (10 to 49 guests), add-on trays and ordering info.

The page is `index.html` (one self-contained file). To publish it, turn on GitHub Pages for the `main` branch.
